# Animal-10 图像分类项目

基于 ResNet-18 的动物图像分类项目，支持训练和可视化预测。

## 环境要求

Python 3.9.25

torch 2.6.0

torchvision 0.21.0

pillow 11.3.0

tqdm 4.67.3

matplotlib 3.9.4

numpy 2.0.2

tkinter


## 文件夹说明

animals10_datasets 文件夹存放原始数据集，包含 train 和 test 两个子文件夹。train 文件夹下是意大利语命名的类别文件夹，每个文件夹内是对应类别的训练图片。test 文件夹结构相同，存放测试图片。这个文件夹的数据是未经处理的原始数据。

processed_datasets 文件夹存放预处理后的数据集，也包含 train 和 test 两个子文件夹。每个子文件夹下是英文命名的类别文件夹，图片已经调整为 224×224 的尺寸并按顺序重命名。该文件夹由 preprocess.py 脚本自动生成。

checkpoints 文件夹存放训练过程中保存的模型权重文件。best_model.pth 是验证集准确率最高的模型，last_model.pth 是最后一个训练轮次的模型。

## 各脚本文件说明

preprocess.py 是数据预处理脚本，将原始图片调整为 224×224 像素，并将文件夹名从意大利语改为英文，图片按顺序重命名后输出到 processed_datasets 文件夹。

dataset.py 定义了数据加载方式和数据增强策略。训练集使用随机裁剪、翻转、颜色抖动等数据增强操作，测试集只做缩放和裁剪，保持评估一致性。

model.py 封装了 ResNet-18 模型，包含模型结构定义、配置参数、训练逻辑、验证逻辑、模型保存和加载功能。支持 GPU 自动检测和早停机制。

train.py 是训练入口脚本，创建模型实例并启动完整训练流程，训练完成后自动保存最佳模型。

app.py 是可视化预测界面，使用 Tkinter 构建图形界面。用户可以通过文件对话框选择图片，在界面中预览图片，然后调用训练好的模型预测图片中的动物类别，并显示预测结果和置信度。
